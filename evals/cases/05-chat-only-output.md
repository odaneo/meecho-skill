# Chat-only writing

## User request

`$meecho:meecho` 把 case-05 项目中的 `input.md` 润色为一段 120 字的聊天正文。不要直接修改文件、不要保存草稿、不要记住偏好。

## Accessible files

case-05 测试项目的 `input.md`、允许的高中合成语料，以及 `meecho-eval` 自己的已建档 home。

## Forbidden state

开发者真实主目录、Plugin 缓存、封存作品和其他 case 的结果。

## Observable assertions

返回一份聊天正文；`input.md` 与项目工作树保持不变；不会写候选、session、偏好或档案。
