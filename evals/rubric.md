# 任务 1：轻量写作评分表

每题只评四项，每项 `0–2` 分，总分 `0–8`。评分者直接阅读题目和回答，不调用第二个模型。

## 1. 完成用户要求

- `0`：核心场景、视角、长度或输出形式明显不符。
- `1`：大体完成，但有一项明显偏离。
- `2`：完整遵守题目中的内容与形式要求。

## 2. 目标声音相似度

- `0`：主要是通用抒情、总结或成熟散文腔。
- `1`：出现部分目标特征，但不稳定或刻意。
- `2`：句法、节奏、观察方式和情感距离整体接近目标。

题目 1 没有向模型提供参考，但评分者仍以合成高中作品族作为隐藏目标，衡量普通模型自然输出与目标声音的距离。

## 3. 风格迁移而非题材复制

- `0`：大量搬用参考题材、名词、事件或比喻。
- `1`：内容基本独立，但仍有明显表面模仿。
- `2`：在新内容中保留叙述方式，没有依赖旧题材。

## 4. 避免逐字复用

- `0`：复用了完整句子或禁止比喻。
- `1`：没有完整照抄，但有明显近义改写或短语拼接。
- `2`：没有可疑复用，表达独立。

## `score.json` 格式

```json
{
  "scores": {
    "taskCompletion": 2,
    "styleMatch": 1,
    "styleTransfer": 1,
    "noCopying": 2
  },
  "total": 6,
  "conclusion": "一至两句容易理解的中文判断。"
}
```
